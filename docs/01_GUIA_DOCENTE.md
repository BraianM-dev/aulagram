# Guía docente · AulaGram v8.6.1

AulaGram es una red social educativa para trabajar HTML, CSS, accesibilidad, ciudadanía digital y nociones de arquitectura web. La interfaz pública se sirve desde GitHub Pages y el backend se ejecuta en Google Apps Script con una carpeta privada de Google Drive del docente.

## Secuencia sugerida

1. Entregar `plantilla-alumno/` mediante CREA.
2. Pedir al grupo que edite primero el perfil localmente.
3. Comprobar rutas relativas e imágenes sin depender de recursos remotos.
4. Trabajar accesibilidad: `alt`, teclado, contraste, zoom y reducción de movimiento.
5. Abrir AulaGram y proporcionar el código de clase.
6. Habilitar publicación desde el panel docente.
7. Luego habilitar progresivamente likes, seguimiento, comentarios y mensajería.
8. Usar los bots como andamiaje; no como sustituto del proceso de resolución.

## Panel docente

El panel permite activar o pausar la red completa y módulos sociales, silenciar usuarios, revisar alertas de moderación, eliminar comentarios o mensajes y generar respaldos.

## Evaluación

La cantidad de seguidores, likes o mensajes no es evidencia de aprendizaje. Conviene evaluar estructura HTML, personalización CSS, accesibilidad, resolución de problemas, explicación del proceso y ciudadanía digital.

## Antes de una clase

- verificar que GitHub Pages cargue;
- comprobar el indicador del backend;
- revisar que el despliegue `/exec` de Apps Script sea la versión correcta;
- entrar al panel docente;
- hacer una publicación de prueba con una copia de la plantilla;
- probar un comentario, un mensaje y un bot;
- confirmar que el respaldo más reciente exista.
