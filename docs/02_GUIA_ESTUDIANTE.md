# Guía del estudiante · AulaGram

Tu objetivo es construir un perfil web propio con HTML y CSS y después publicarlo dentro de una comunidad educativa.

Trabajá con `perfil.html`, `estilo.css` e imágenes locales. Usá un alias, evitá datos personales y conservá las clases que AulaGram necesita para reconocer el perfil. Antes de publicar, abrí tu HTML en el navegador, recargá después de cada cambio y observá qué efecto produce el código.

Cuando el docente habilite AulaGram, ingresá el código de clase, abrí **Publicar**, subí HTML, CSS y todas las imágenes. Si el validador informa un problema, volvé a tu código, corregí y reintentá. La primera publicación genera un código de recuperación de seis dígitos: guardalo y no lo compartas.

Después podés explorar perfiles, seguir, dar Me gusta, comentar y enviar mensajes cuando esos módulos estén habilitados. También podés hablar con `@byte_bot`, `@html_bot`, `@css_bot`, `@js_bot`, `@python_bot`, `@ia_bot`, `@a11y_bot` y `@lan_bot`.

Probá mensajes como `hola`, `¿cómo te llamás?`, `menú`, `reto`, `quiz`, `dato random` o una pregunta concreta de informática. Los bots pueden equivocarse o no entender una consulta: reformular y verificar también forma parte de la actividad.
