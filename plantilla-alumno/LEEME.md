# Plantilla del estudiante · AulaGram

Esta carpeta contiene **todo lo que el estudiante necesita editar** para la actividad de 9.º EBI. El trabajo principal continúa siendo HTML + CSS: no hace falta programar JavaScript para publicar el perfil.

## Qué se puede editar

- `perfil.html`
- `estilo.css`
- los archivos dentro de `imagenes/`

Las imágenes incluidas son **recursos de prueba**. Se pueden reemplazar por imágenes adecuadas para la actividad, guardadas localmente dentro de `imagenes/`.

## Qué no se debe borrar

AulaGram utiliza estas clases para reconocer el trabajo al publicarlo:

- `nombre-usuario`
- `biografia`
- `foto-perfil`
- `publicacion`

Cada `article.publicacion` debe tener una imagen local, un título `h2` o `h3` y un párrafo.

## Antes de publicar

1. Elegí un alias que no sea tu nombre completo.
2. Cambiá avatar y biografía.
3. Creá al menos dos publicaciones.
4. Personalizá el CSS.
5. Revisá que las imágenes tengan `alt` útil.
6. Abrí `perfil.html` directamente en el navegador y comprobá que funcione.
7. Probá teclado, zoom/texto grande y reducción de movimiento.
8. Subí `perfil.html`, `estilo.css` y **todas** las imágenes utilizadas.
9. Guardá el código de recuperación de 6 dígitos que entrega AulaGram la primera vez.

## Privacidad y convivencia

No publiques teléfono, correo personal, dirección, contraseñas ni otros datos sensibles. La mensajería de AulaGram es educativa y puede ser moderada por el docente. Los seguidores, likes y cantidad de mensajes **no forman parte de la calificación**.
